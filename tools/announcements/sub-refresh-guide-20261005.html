🌐 برای دریافت سرورهای جدید، ساب رو آپدیت کنید رفقا، تغییرات سرورها وقتی داخل برنامه‌تون میاد که لینک سابسکریپشن رو به‌روز کنید. فقط باز کردن برنامه یا تست پینگ کافی نیست؛ آپدیت خودِ برنامه هم کار جداگانه‌ایه. 📱 اندروید • AtlasV2: تنظیمات ← بخش «اشتراک» ← «به‌روزرسانی الان». • v2rayNG: گروه ساب اطلس رو انتخاب کن ← سه‌نقطهٔ بالای صفحه ← Update subscription. • Hiddify (اندروید و آیفون): پروفایل اطلس رو انتخاب کن ← دکمهٔ فلش چرخشیِ آپدیت پروفایل در صفحهٔ خانه. ⚡ آیفون / iOS • Shadowrocket: صفحهٔ Home ← علامت آپدیت کنار عنوان گروه ساب، بالای سرورها. • Streisand: روی عنوان ساب نگه دار ← Update. • V2Box: Configs ← + ← Update All Subscriptions. روی اسم برنامه‌ها بزن تا آموزش تصویری فارسی باز بشه؛ جای دکمه‌ها ممکنه بین نسخه‌ها کمی فرق کنه. ✅ تا پیام موفقیت آپدیت رو ندیدی، ساب به‌روز نشده. بعدش سرورهای تازه رو تست کن. اگر آپدیت خطا داد، VPN رو خاموش کن و دوباره امتحان کن؛ در صورت نیاز اینترنت رو عوض کن. از دکمهٔ پایین وارد «سرویس‌های من» شو، سرویس خودت رو باز کن و لینک ساب تازه رو بگیر. قبل از حذف ساب قبلی، مطمئن شو لینک تازه با موفقیت وارد شده.
